# Draft disclosure — `working/section8_amendment_draft.md`

This note discloses the existence and disposition of a working draft file referenced in `VIPI_v0.1.3_chain_of_custody.md` §5.1, in service of the no-silent-elision requirement stated in Chain of Custody §5.1's `e14f435` entry.

## What

The patch file `verification/s05-e14f435.patch` exports the diff of commit `e14f435`, which materially advanced the Methodology §8.2 anchor regime from 3 to 12 (sub_index, value_kind) pairs and the §8.4 VIPI-Best provider-selection clarification. Within that diff, the commit also added a working file at `docs/vipi/working/section8_amendment_draft.md` containing in-progress prose related to the §8.2 amendment.

## Status of the working file

The `docs/vipi/working/` subtree was added to `.gitignore` at commit `46ac7b7` on 2026-05-18 as part of the publication-infrastructure commit. The working file is therefore not present on the v0.1.3 published Methodology surface (the files enumerated in Chain of Custody §2) and is not part of any version-pinned artifact in this mirror's canonical or `history/` directories.

The working file is visible in the `s05-e14f435.patch` diff as a one-time disclosure of pre-publication drafting. The substantive content of commit `e14f435` — the §8.2 12-anchor regime and §8.4 VIPI-Best clarification — is in the Methodology as published. The working file's prose did not enter the published Methodology surface in the form it appears in `e14f435`; the published §8.2 and §8.4 language is the authoritative text.

## Why this disclosure exists

Chain of Custody §5.1 already discloses commit `e14f435` and the existence of a working draft therein. This note exists because the patch export in this mirror's `verification/` subdirectory makes that draft directly readable, where in the source monorepo a reviewer would need to run `git show e14f435` to see it. A reviewer encountering the working file in the patch export may read it as authoritative Methodology text, as evidence of pre-publication scope confusion, or as a leak of internal drafting; this disclosure exists to head off all three readings.

The disclosure pattern is governed by the Chain of Custody §5.1 no-silent-elision requirement applied to a reading-surface change. The Chain of Custody §11 documentation-errata protocol is the structurally-analogous "disclose on the face" pattern for corrections to substantive content, which the present disclosure is not; §5.1's no-silent-elision requirement is the load-bearing source for presence-disclosures of files visible in patch exports.

## Scope

This disclosure applies to the working file in the `s05-e14f435.patch` export only. No other working drafts or pre-publication prose are present in this mirror's `verification/` exports.
